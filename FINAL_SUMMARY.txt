================================================================================
                          BUILD & DEPLOYMENT STEPS
================================================================================

Step 1: PREPARE RASPBERRY PI
  → Install Raspberry Pi OS (Bullseye or newer)
  → Connect 3.5" touch display
  → Enable SSH (optional)

Step 2: INSTALL DISPLAY DRIVER
  → For Waveshare: git clone LCD-show repo
  → Run LCD35-show installer
  → Configure display in /boot/config.txt

Step 3: BUILD APPLICATION
  → chmod +x build.sh
  → ./build.sh
  → Wait 10-15 minutes for compilation

Step 4: ENABLE AUTOSTART
  → sudo systemctl enable MusicPlayerOS
  → sudo reboot

Step 5: ADD MUSIC
  → mkdir ~/Music
  → Copy music files to ~/Music/

Step 6: CALIBRATE TOUCH
  → Open Settings app
  → Tap "Calibrate Touch Screen"
  → Follow on-screen instructions

Step 7: ENJOY!
  → Music Player OS is ready to use

                          TROUBLESHOOTING QUICK REFERENCE
================================================================================

Problem: Won't start
Solution: Check systemd logs: journalctl -u MusicPlayerOS -f

Problem: Touch not working
Solution: Run Settings → Calibrate Touch Screen

Problem: No music playing
Solution: Check ~/Music directory has .mp3/.wav/etc files

Problem: Build fails
Solution: Run sudo apt-get install --reinstall qt5-default

Problem: Display shows nothing
Solution: Check /boot/config.txt display settings
